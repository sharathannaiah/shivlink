description: Creating polished UI components with attention to visual design, spacing, typography, and overall aesthetics
---

Help create visually appealing and well-designed UI components that follow modern design principles. Focus on creating distinctive, high-quality interfaces rather than generic AI-generated aesthetics.

When working on UI components, consider:

1. **Visual Hierarchy**
   - Establish clear visual hierarchy through size, color, and spacing
   - Guide user attention to important elements
   - Use contrast effectively for readability

2. **Spacing and Layout**
   - Apply consistent spacing using an 8px grid system
   - Ensure proper padding and margin for breathing room
   - Align elements properly to create visual harmony
   - Use whitespace intentionally to group related elements

3. **Typography**
   - Choose appropriate font sizes, weights, and line heights
   - Establish clear typographic hierarchy (h1-h6, body, caption)
   - Ensure sufficient contrast between text and background
   - Limit font families to maintain visual consistency

4. **Color Usage**
   - Use color purposefully to convey meaning and evoke emotions
   - Maintain accessible color contrast ratios (WCAG AA/AAA)
   - Apply colors consistently throughout the interface
   - Consider color blindness and accessibility

5. **Component Design**
   - Design reusable, composable components
   - Consider component states (default, hover, active, disabled, loading)
   - Provide clear affordances for interactive elements
   - Design for different screen sizes and breakpoints

6. **Attention to Detail**
   - Use subtle shadows, borders, and elevations appropriately
   - Apply consistent border-radius values
   - Consider micro-interactions and animations
   - Ensure pixel-perfect alignment when possible

7. **Accessibility**
   - Ensure keyboard navigability
   - Provide proper ARIA labels and roles
   - Design for screen reader compatibility
   - Consider focus states and visible outlines

When implementing UI components:
- Start with grayscale layouts to establish spacing and hierarchy
- Add color intentionally after establishing the structure
- Test designs at different screen sizes
- Consider edge cases and empty states
- Seek balance between aesthetics and usability

For this shivlink project specifically:
- Maintain consistent use of Tailwind utility classes
- Follow the existing design patterns in Hero, Navbar, and PlanCard components
- Ensure mobile responsiveness
- Use Framer Motion for subtle, purposeful animations
- Maintain dark/light mode compatibility
